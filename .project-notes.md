## 📋 Project Requirements & Rules

### Core Principles
1. **SỬA trước THÊM MỚI** - Ưu tiên fix/improve code hiện có hơn là thêm mới gây conflict
2. **Giữ tính nhất quán** - Naming conventions, code style phải consistent
3. **Logic trước UI** - Đảm bảo logic đúng trước khi polish UI

### Technical Stack
- **Frontend**: Vanilla JS, Vite, no framework
- **Backend**: Express.js on Vercel Serverless
- **Database**: PostgreSQL (Neon for dev, Ubuntu VM for prod)
- **Auth**: Privy SDK
- **LLM**: Gemini (primary), OpenAI (fallback)
- **TTS**: Deepgram Aura-2 (primary), Gemini/Browser (fallback)

### Key Features
1. **JLPT Practice** - N5 to N1 levels
2. **3 Modes**: Basic (1/3), Standard (2/3), Official (full)
3. **3 Sections**: Vocab-Grammar, Reading, Listening
4. **Progressive Loading** - Load groups one by one for faster start
5. **Smart TTS**:
   - Non-dialogue → single segment + cache
   - Dialogue → streaming + hybrid combine for seek
6. **Grading Options**:
   - Quick (instant, no AI)
   - AI (detailed feedback)

### Parallel Stream Generation Architecture (Mới thêm)
- **Pipeline A (Ưu tiên hiển thị - Main Stream)**: 
  - Generates Từ vựng/Ngữ pháp (Vocab) ngay lập tức.
  - Sử dụng **Parallel Batching**: Gửi 3-4 requests chunk song song.
  - Context được update sau mỗi batch để giữ mạch văn.
- **Pipeline B/C (Background Groups Stream)**:
  - Chạy **ngay lập tức** khi bắt đầu bài thi (song song với Stream A).
  - Load toàn bộ các nhóm còn lại (Reading, Listening...) trong background.
  - Đảm bảo trigger đúng 1 lần (atomic logic).

### Adaptive Optimization (Updated 2026-01-16)
Hệ thống tự động điều chỉnh tài nguyên dựa trên Level và loại bài:

#### Model Selection:
- **N5, N4**: `gemini-2.5-pro` (Tối ưu tốc độ, RPM 250)
- **N3, N2, N1**: `gemini-3-pro` (Ưu tiên chất lượng, RPM 25)

#### Concurrency Strategy:
| Loại bài | 2.5-pro (N4/N5) | 3-pro (N1/N2/N3) |
|----------|-----------------|------------------|
| **Single-section** | **7** parallel | **5** parallel |
| **Full exam** | **7** parallel | **4** parallel |

#### Universal Initial Batch:
- **ALL Full Exams / Large Groups**: Load **2 requests (chunks)** đầu tiên song song để tạo buffer (thay vì 1).
- Áp dụng cho mọi Level/Language (không chỉ N5 hay JLPT).

#### Parallel Loading:
- Single-section với ít mondai: Send ALL chunks đồng thời
- Console log: `Parallel loading (3-pro): Sending ALL 4 chunks simultaneously`
