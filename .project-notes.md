## 🏗️ V2 Pool Architecture (New)

```
┌─────────────────┐     ┌──────────────────┐     ┌───────────────────┐
│   Client App    │────▶│  /api/exam/start │────▶│ mondai_bank       │
│                 │     │  Returns:        │     │ (pre-pooled Qs)   │
│  RequestQueue   │     │  - instance_key  │     └───────────────────┘
│  (concurrency 3)│     │  - first chunk   │              │
└─────────────────┘     └──────────────────┘              │
        │                        │                        │
        ▼                        ▼                        ▼
┌─────────────────┐     ┌──────────────────┐     ┌───────────────────┐
│ loadRemaining   │────▶│  /api/exam/chunk │────▶│ exam_instances    │
│ ChunksV2()      │     │  (concurrent)    │     │ (blueprint cache) │
│ (parallel load) │     └──────────────────┘     └───────────────────┘
└─────────────────┘              │
        │                        ▼
        ▼               ┌──────────────────┐
┌─────────────────┐     │ /api/exam/       │
│ quickGradeV2()  │────▶│ quickgrade       │
│                 │     │ (UPSERT attempts)│
└─────────────────┘     └──────────────────┘
```

### Key Features:
- **Concurrent chunk loading**: `loadRemainingChunksV2()` uses `RequestQueue` with limit 3
- **Faster delay**: Reduced from 500ms to 300ms between chunks
- **UPSERT pattern**: `attempts` table uses `ON CONFLICT DO UPDATE`

### Emphasis Markers
- LLM uses `[[word]]` markers for kanji/vocab emphasis
- `escapeHtml()` converts to `<strong class="hl">`
- `.hl` class: bold + gradient underline

## 📋 Project Requirements & Rules

### Core Principles
1. **SỬA trước THÊM MỚI** - Ưu tiên fix/improve code hiện có
2. **Giữ tính nhất quán** - Naming conventions, code style
3. **Logic trước UI** - Đảm bảo logic đúng trước
4. **Minimal diffs** - Patch nhỏ, không rewrite file

### Technical Stack
- **Frontend**: Vanilla JS, Vite, no framework
- **Backend**: Express.js on Vercel Serverless
- **Database**: PostgreSQL (Neon for dev, Ubuntu VM for prod)
- **Auth**: Privy SDK
- **LLM**: Gemini (primary), OpenAI (fallback)
- **TTS**: Deepgram Aura-2 (primary), Gemini/Browser (fallback)
